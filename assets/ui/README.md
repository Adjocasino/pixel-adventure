# UI mockups (pictures only, not in game yet)

`tools/controls_mock.py` renders these.

## Mobile controls: **Option B chosen** (`controls_option_b.png`)
- Floating joystick on the left.
- Bottom-right: big green **Action** button (talk, open, pick up, pet).
- Three smaller buttons on an arc around Action:
  - orange **Run** (hold to sprint, or broom for Inad)
  - pink **Emote**
  - blue **Item** (use the held tool)
- Top-right small buttons stay as menus (travel/sound; bag and character swap are candidates).

Option A (an equal-size diamond) was not chosen.
